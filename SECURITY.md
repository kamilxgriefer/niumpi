# Security Policy

## Supported versions

Niumpi is under active development. Security fixes are provided for the latest production deployment and the current `main` branch.

| Target | Supported |
| --- | --- |
| Latest production deployment | Yes |
| Current `main` branch | Yes |
| Older deployments, tags and feature branches | No |

## Reporting a vulnerability

Please do not report suspected security vulnerabilities through public GitHub issues, discussions or pull requests.

Use GitHub's private vulnerability reporting feature for this repository:

1. Open the repository's **Security** tab.
2. Choose **Advisories**.
3. Select **Report a vulnerability**.

Include as much of the following information as possible:

- a clear description of the issue;
- the affected page, feature, component or dependency;
- exact steps to reproduce it;
- the potential impact;
- relevant screenshots, logs or a minimal proof of concept;
- browser, operating system and device details where relevant;
- any suggested mitigation, if known.

## Responsible testing

When investigating a suspected vulnerability:

- use your own account and data;
- stop once you have enough evidence to demonstrate the issue;
- do not access, modify, retain or disclose data that does not belong to you;
- do not disrupt the service, degrade availability or run denial-of-service tests;
- do not use social engineering, phishing or credential attacks;
- do not run broad automated scans against production without prior permission;
- do not publish exploit details before a fix or coordinated disclosure date is agreed.

## Response process

We aim to:

- acknowledge a report within 5 business days;
- provide an initial assessment within 10 business days;
- share progress updates when additional investigation is required;
- correct confirmed vulnerabilities as soon as reasonably possible, based on severity and complexity.

A report may be accepted, declined or classified as informational after investigation. The reporter will receive an explanation whenever possible.

## Scope

This policy covers the Niumpi code in this repository and the current Niumpi production deployment. Vulnerabilities that exist only in an unrelated third-party product should be reported to that product's maintainer, unless the issue is caused by Niumpi's integration or configuration.

Thank you for helping keep Niumpi and its players safe.
