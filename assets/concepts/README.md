# Koncepcje Niumpiego

Wstępne grafiki poglądowe wygenerowane podczas projektowania postaci.

## Główna zasada ewolucji

- Listki zapisują jakość i charakter relacji z opiekunem.
- Ręce pokazują dojrzałość oraz rosnącą samodzielność Niumpiego.
- Niumpi zaczyna bez rąk, następnie wyrastają mu dwa symetryczne zalążki, a później dwie pełne ręce.

Plik `arms-evolution.png` przedstawia obowiązujący kierunek anatomii. Wcześniejsze warianty charakteru nadal służą jako inspiracja dla wyglądu listków, ale zawierają starą, jednorożną wersję anatomii.
